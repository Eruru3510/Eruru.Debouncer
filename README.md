# Eruru.Debouncer

A high-performance, thread-safe, AOT-compatible asynchronous debouncer for .NET.

Designed for throttling rapid repeated operations such as UI input handling, search suggestions, configuration persistence, file watching, auto-save, delayed refresh, and any scenario where only the latest invocation should execute after a quiet period.

一款高性能、线程安全、兼容 AOT 的 .NET 异步防抖器。

专为处理频繁重复触发的操作而设计，例如 UI 输入事件、搜索建议、配置保存、文件监听、自动保存、延迟刷新，以及任何只希望在一段静默期后执行最后一次调用的场景。
